# 视觉复核

## Scope

用桌面 Edge 查看 1440×900、1366×768 的观测和串口页面、完整实验记录、投屏及设备确认框，并查看 390×844 布局的移动端全页图。用 `innerWidth`、断点匹配及页面宽度确认实际布局。320、375、768、1024、1920 宽度另外做了布局检查，不把这些视作逐屏目视验收。

## Cold read

两舱读数先入眼，其次是共轴图和温升差，连接状态不需要在设备区寻找。观测页在窄屏仍可并排比较；调试页先读命令区，再向下查日志，不把桌面双栏硬挤到手机上。投屏保留模拟标签，不让演示数字看起来像实测。

## Coverage

| 维度 | 实际检查 | 结果 |
|---|---|---|
| 构图、层级 | 宽屏与笔记本观测，投屏截图 | 通过 |
| 排版、密度 | 390 宽三页；实验结果和公式输入为常规长度 | 通过 |
| 颜色、识别 | A 实线/B 虚线，文字与背景常见搭配的对比度独立计算 | 通过 |
| 交互反馈 | 调试命令区、确认框、实验开始/结束及导出 | 通过（浏览器模拟） |
| 响应与键盘 | 断点溢出、左右键、Escape、安全默认焦点 | 通过 |
| 实物与辅助技术 | 实体 Nano、投影机、读屏软件、系统放大 | 未验收 |

## Findings

- 已修正投屏图表加高导致温升差落在视口下方的问题。1440×900 的最终截图可见完整结果；1366×768 和 1920×1080 另做边界检查。
- 已将调试输入和回执移到日志上方；窄屏时间戳不再断行，原始报文仍可折行查看。

## Considered and rejected

不采用大幅静态插画、通用霓虹或仪表盘堆叠。温室实验的视觉焦点应是两条可核对的曲线，以及在教室里能看清的真实读数。

## Verdict and gate

布局和模拟使用可交付。网页没有伪装成实测的默认数据；设备选择、驱动和执行器仍须上机验收。
