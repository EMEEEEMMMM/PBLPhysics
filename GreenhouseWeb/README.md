# Thermarium | 双舱温室观测台

为 WFLA 物理 PBL 做的本地网页。**不需要 npm、联网或安装网页后端**。整个 `GreenhouseWeb` 文件夹一起复制，不要只复制 `index.html`。

## 打开网页

1. Windows 双击 `open-in-edge.cmd`，或用桌面版 **Edge / Chrome** 打开 `index.html`。首次进入会看到明确标注的**模拟数据**，可以先试投屏、记录和调试；模拟命令不会发到硬件。
2. 要接板子时，用**能传数据的 USB 线**连接 Nano，关闭 Arduino IDE 的串口监视器及可能占用 COM 口的程序。
3. 点击 **连接 Arduino**，选对应端口。学校原版和双舱版都是 **115200 baud**。打开串口可能会重启 Nano，等约 5–15 秒看首帧。识别固件后，进入**串口调试 → 读取状态**。
4. 如果学校电脑的浏览器在本地文件页面不给串口权限，进入 `GreenhouseWeb` 文件夹打开终端，运行 `python -m http.server 8000 --bind 127.0.0.1`，然后用 Edge/Chrome 打开 `http://localhost:8000`。`file://` 与 `localhost` 的本机记录分开，建议选一种固定使用。

顶部「模拟数据 / 未连接」按钮可在无设备时切换数据源。断线不会把模拟值自动填到实测界面。
按小组最终稿接线时，Nano 只由 USB 供电、外部 5 V 与 Nano 只共地。若沿用学校原图的外部 5 V 接法，请先确认供电，再插电脑 USB。

## 用它完成一次实验

- **实时观测**：左舱 A（湿海绵）、右舱 B（混凝土）并排显示温度、相对湿度和 CO₂，SCD40 约每 5 秒更新一组。趋势图可以切换指标及时间范围，实线是 A、虚线是 B。支持鼠标或左右方向键核对样本；断线或约 15 秒没有新读数会显示相应状态。
- **实验记录**：选择对照、加水雾、增加 CO₂ 或其他条件，按实际情况填写设定值及可选的舱外温湿度。等读数稳定后**手动开灯、立即点击「标记开灯并开始」**。默认记录 10 分钟。可标记调整 CO₂、改变湿度等试验事件；实际执行情况以你的现场观察为准。
- **温升**：各舱分别用最近的开灯前读数作基线。双舱基线须在 15 秒内更新，且接收时刻相差不超过 8 秒。结束温升取截至结束时向前 15 秒内的最后有效新读数；双舱差值还要求结束样本相差不超过 8 秒。不足时留空，不插值，不拿过期读数代替。CSV 同时保留电脑接收时间（UTC）和板端 `millis()`（如有）。
- **留存与报告**：列表保存不同设定的多轮实验；可下载单次温度图（SVG），导出单次或全部实验为 CSV（含基线、测量值、结果与事件）。实测保存在当前浏览器，建议每轮导出备份；关闭/刷新会中断记录，清理浏览器数据会丢失本机档案。模拟记录在本页内单独保存，导出的文件名含 `SIMULATED`，不能作为实验结果。

依据总课件 PDF 第 4–5、27 页和小组方案书中的测量要求。实际测试仍须按课件要求**多档改变同一自变量、控制光照时长等变量**。网页不自动调节 CO₂，也不替代实体箱外温湿度计。观测页折叠区提供 [Humidex 湿热参考值](https://www.ccohs.ca/oshanswers/phys_agents/humidex.html)，按 `T + 5/9 × (e − 10)` 计算；`e` 是由温湿度估得的水汽分压（hPa）。该值不考虑灯辐射或风速，不是灯下的真实体感温度。

## 两套 Arduino 程序的区别

| 固件 | 采集 | 网页调试 |
|---|---|---|
| 学校 `greenHouse.ino` | 单舱，读文本格式的 CO₂、温度、湿度 | 监看和保存 RX。原程序没有读入命令的代码，网页不控制它的风扇或雾化器。|
| 小组 [`GreenhouseDual.ino`](../GreenhouseDual/GreenhouseDual.ino) | v1.1 默认按学校 PPT 单侧接线（风扇 D2、雾化 D3、SCD40 A4/A5、OLED D13/D11/D9/D8）；接上 TCA9548A 后自动变双舱 | `STATUS`、`SCAN`、`HELP`、`FAN ON/OFF`、`MIST [A/B] ON/OFF`、`RH [A/B] <1–95>/OFF`、`STOP`；按键式模块还支持 `PULSE [A/B]` 和 `SYNC [A/B] ON/OFF`。 |

- 明日单传感器实验室测试：只接 1 颗 SCD40 到 Nano `A4/A5`、风扇继电器到 `D2`、雾化三极管到 `D3`、OLED 到 `D13/D11/D9/D8`。程序开机自动识别无 TCA9548A 并进入单传感器模式，OLED 全屏显示单舱温湿度与 CO₂；网页端可用顶部「单传感测试区域」切换记录 **A 湿海绵舱** 或 **B 混凝土舱**，并在「实验记录 → 叠加对照」中把两次单舱实验同轴对比。
- `MIST ON/OFF`（不写舱号）在双舱模式下发给两舱，在单传感器模式下仅操作 A 通道（D3）。自动湿度反馈由 Nano 执行，低于目标减 2 %RH 时尝试开启，达到目标时尝试关闭。界面将收到 `OK` 与设备的物理状态分开：**`OK` 只代表板端受理**。
- 小组最终接线保留 D7、没有灯控支路。网页只做开关灯打点，计时结束**不会自动关灯**。`STOP` 只发送现有固件的停机请求，不是物理断电；断开浏览器也不会可靠地停止负载。首次联调请在现场确认雾化器水位、按键状态和风扇，准备好用实体电源开关停机。
- 网页调试是读写串口，不做固件刷写、断点或程序上传。原有两个 `.ino` 文件都没有更改。SCD40 的 400–2000 ppm 是标称精度范围；如果实验采到范围外的读数，报告应注明。
- 第一次联调可先接传感器、暂不接执行器负载，验证 115200 下收得到读数、`STATUS` 回 `STATE`，再逐路验证板端和实物动作。

## 开发验证

```powershell
node --test tests/telemetry.test.js
python tests/browser_smoke.py
```

第二条需要 Python Playwright 和桌面版 Edge；仅用于开发测试。测试模拟了串口分包、命令回执、拒绝、超时、拔线、重连和单舱识别。需要在实物上再验收 USB 驱动、实际采样与执行器是否正确响应。
