    课件测试要求

    按组记录同一自变量的多档设定，课件要求至少改变五次。水雾组可按小组方案试 40 / 50 / 60 / 70 / 80 %RH；加 CO₂ 组可试 600 / 1200 / 2500 / 4000 / 6000 ppm。若只有一颗传感器，可先测完 A 侧并保存，再切换单传感区域后测 B 侧，并用「叠加对照」对比。

      连不上或收不到数据？

      用桌面版 Edge 或 Chrome；先关闭 Arduino IDE 的串口监视器，使用可传数据的 USB 线。学校和双舱版都默认 115200。Nano 打开串口时可能复位，等约 5–15 秒看首帧。没有 COM 口时检查设备管理器和 CH340/CH341 驱动。若怀疑 SCD40 未接牢，可点右侧「扫描 I²C」。
